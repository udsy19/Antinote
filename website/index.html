Keywords

The first word decides.

Every note starts as plain text. Put a keyword on the first line and the note changes what it does. Delete the word and it’s plain text again.

  • listtodo · checklist · tasks

    Every line becomes a checkbox. Click to tick it, or end the line with /x.

    farmers market

    fix the bike light

  • mathcalc

    Lines ending in = get answered. Units, currencies, percentages, variables and ans.

    89 miles to km = 143.23 km

    €96 × 3 = €288.00

  • sumavg · count

    Totals everything below the first line, even numbers inside sentences. // skips a line.

    bread €4.20

    cheese €11.50

    Total: €15.70

  • timerstopwatch · pomodoro · breathe

    Countdowns, stopwatches, pomodoros and a breathing rhythm. They keep running in the menu bar.

    timer 5:30 tea 05:30 · tea

  • codesnippet

    Highlighting for Swift, Python, JavaScript, Go, Rust, SQL and more. Pasted text stays exactly as copied.

    const each = total / 3

  • pasteautopaste

    Press Return on the first line and everything you copy lands here, cleaned up, one item per line.

    https://maps.app/lisbon

    Rua Augusta 24

Privacy

Your notes stay on your Mac.

Notes live in a SQLite database in your Library folder. There’s no account, no analytics and no telemetry. Anything that touches the network has its own switch, and Turn Everything Off makes Super Notes fully offline.

  • No account
  • No analytics
  • No telemetry
  • Open source

Settings › Privacy

  • Currency rates

    Downloads daily exchange rates for currency math. Sends nothing of yours.
    On by default

  • App updates

    Checks GitHub Releases every few hours and installs new versions in the background. Sends nothing of yours.
    On by default

  • Extension updates

    Checks GitHub for updates to extensions you installed from there.
    Off by default

  • Extension APIs

    Lets extensions call the endpoints they declare, with keys you grant.
    Off by default

  • Sync notes and preferences

    Writes end-to-end encrypted copies to your own iCloud Drive.
    Off by default

Currency rates and app updates are the two switches that start on. Turn rates off and currency math uses the last rates it saw, or your own.

Questions

Good to know.

Is it really free?

Yes. Super Notes is MIT licensed, with no account, no subscription and no paid tier. The source is on GitHub.

macOS says it can’t open Super Notes. Now what?

Super Notes isn’t notarized by Apple, so the first launch of a downloaded DMG needs System Settings › Privacy & Security › Open Anyway, once. The one-line installer doesn’t need this step.

Which Macs does it run on?

macOS 14 Sonoma or later, on Apple silicon and Intel. It’s a native Swift app with no third-party dependencies.

Does anything leave my Mac?

Only when a network feature is switched on. Currency rates start on and download daily exchange rates without sending anything of yours. Extension updates, extension APIs and sync start off. Settings › Privacy has a switch for each, plus Turn Everything Off.

Can I use it on more than one Mac?

Turn on sync and Super Notes writes end-to-end encrypted copies to your own iCloud Drive. Notes are sealed with AES-GCM on your Mac first.

Can I write my own :: commands?

Yes. An extension is a folder with an extension.json and an index.js, run in its own JavaScript context. Install more from GitHub in Settings › Extensions, or drop a folder into ~/Library/Application Support/Super Notes/Extensions.

How do I update or uninstall?

Run the install command again to update. To remove it, add -s -- --uninstall after bash.

I used Jotter. What happens to my notes?

Super Notes was called Jotter. Your notes, settings and keys move over automatically the first time it opens.
