Super Notes in three facts

Open source

Every line is on GitHub, free to read, fork and keep.

No account

Nothing to sign up for. Nothing phones home.

Native

Swift and AppKit. No Electron, no dependencies.

Install in one line

Fetches the latest release, moves it to Applications and opens it.

curl -fsSL https://udsy19.github.io/super-notes/install.sh | bash

Or download the DMG. Apple silicon and Intel.

FAQ

How much does Super Notes cost?

Nothing. Super Notes is free and open source under the MIT license. There's no trial, no license key and no paid tier. The source is on GitHub.

Is there a mobile version?

No. Super Notes is a Mac app, built to sit one keystroke away while you work.

Which versions of macOS does it support?

macOS 14 Sonoma or later, on Apple silicon and Intel. See-through windows need macOS 15 Sequoia.

macOS says it can't open Super Notes. Now what?

Super Notes isn't notarized by Apple, so the first launch of a downloaded DMG needs System Settings › Privacy & Security › Open Anyway, once. The one-line installer skips this step.

Are my notes synced or backed up?

Notes live in a database on your Mac, with automatic daily backups. Sync is off until you turn it on; then encrypted copies go to your own iCloud Drive, sealed with AES-GCM on your Mac first. You can also export any note to Apple Notes, Obsidian, Bear, Markdown, plain text or PDF.

Do you collect any data?

No. No account, no analytics, no crash reports. Settings › Privacy lists everything that can reach the network, each with its own switch, and Turn Everything Off makes Super Notes fully offline. Details are in the privacy policy.

How is this different from Apple Notes, Obsidian or Bear?

Those apps are built for keeping and organizing. Super Notes is built for the next few minutes: no titles, no folders, and empty notes clean themselves up. Anything worth keeping goes to the app you already use in one keystroke.

Does it work with Raycast, Alfred or Shortcuts?

Yes, through the supernotes:// URL scheme: create a note, append to it, replace it, show it or search. It works from Terminal too.

Can I write my own :: commands?

Yes. An extension is a folder with an extension.json and an index.js, run in its own JavaScript context. Install more from GitHub in Settings › Extensions.

I found a bug or have an idea.

Thank you! Open an issue on GitHub. Security problems go privately, as described in SECURITY.md.

How can I help?

Star the repository, send a pull request, or write a theme or an extension and share it. CONTRIBUTING.md explains how to get started.

Telling a friend who keeps forty sticky notes on their desktop helps a lot too.
